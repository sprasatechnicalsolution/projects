## The idea

A portfolio built like a small publication: projects and engineering notes written in Markdown, reviewed, scheduled and published, with the speed and security of a modern Python stack.

## Built in six phases

| Phase | What it added |
|---|---|
| 1 | Public site, design system, authentication, security and SEO foundations |
| 2 | Full admin: projects, notes, tags, messages, settings, Markdown editor |
| 3 | Media library with responsive images, draft preview links, search, clean-up of old data |
| 4 | Email queue with retry, revision history, auto-generated social share cards, in-editor media picker |
| 5 | Roles and authorship, scheduled publishing, PostgreSQL full-text search, verified backups |
| 6 | Job monitoring and alerts, editorial review, author pages, rate limiting, newsletter |

## Key features

- Server-rendered pages: fast, and readable by search engines
- Projects and engineering notes with tags and full-text search
- Markdown editor with media picker and revision history
- Draft preview links to share before publishing
- Scheduled publishing and editorial review
- Social share images generated automatically for every post
- Newsletter and contact messages
- Backups that are tested, not just taken; job monitoring with alerts
- One-command setup with Docker; migrations run automatically
