# Pradip Subedi · Sprasa Technical Solution: Project Portfolio

Websites, business software, e-commerce, design and engineering work, built in Chitwan, Nepal.
Each folder is a **client-facing overview** of one project: what the client needed, what we built, screenshots and the technology used. Source code is not included here.

## Services we offer

| Service | What you get |
|---|---|
| **Business websites** | Fast, mobile-first sites with SEO, WhatsApp and call buttons, and an admin panel to edit everything |
| **E-commerce** | Online shops with eSewa, Khalti and cash on delivery, plus stock and order management |
| **Booking and appointment systems** | Live time slots, SMS/OTP confirmation, reminders and staff calendars |
| **Business software** | HR and payroll, IRD-aligned billing and accounting, ERP, CRM, hotel front office |
| **News portals and CMS** | Newsroom workflow, ad management, SEO and installable apps |
| **Education platforms** | Consultancy CRM, school and college CMS, online courses with certificates |
| **Graphic design and video** | Social media kits, print menus, promo videos with Nepali voice-over |
| **WordPress** | Custom themes and plugins, news and portfolio sites |
| **AI tools and automation** | AI writing helpers in your software, agent skills, content tools |
| **Electrical, electronics and IoT** | Control systems, embedded firmware, PCB design, power-system analysis |
| **Hosting, domains and support** | `.com.np` domains, deployment, security audits and maintenance |
