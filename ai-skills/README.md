## The idea

AI agents can write a landing page or a resume, but quality varies from run to run. Each skill here gives the agent a clear workflow, strict input checks, design and quality standards, explicit "never do this" rules, and small scripts that check the result offline before it is handed over.

## The ten skills

| Skill | What it produces | Built-in checks |
|---|---|---|
| Landing page builder | Single-file landing page | Accessibility, light/dark contrast, SEO, Open Graph, script safety |
| Portfolio maker | Personal portfolio site and profile data | Profile validation, HTML audit |
| PDF maker | Styled, paginated PDF from Markdown or JSON | PDF verification |
| Social card generator | Open Graph, GitHub and square cards (SVG + PNG) | SVG validation |
| Code cleaner | Safe refactors for Python, PHP, JS, TS | Code-smell scan before and after, syntax check |
| Text humanizer | Natural rewrites that keep every fact | Scans for AI-sounding phrases |
| SEO blog writer | SEO articles that also read naturally | SEO check with FAQ schema + humanizer |
| README generator | Verified GitHub READMEs with table of contents | README lint |
| Email template builder | Responsive HTML email for Gmail, Outlook, Apple Mail, with dark mode | Email lint |
| Resume builder | ATS-friendly resumes tailored to a job | ATS check, PDF export |

## Key features

- Three levels in every skill: Starter, Pro and Enterprise
- Nothing to install beyond Python 3.8; checks run offline
- One-line installer for all skills, one project, or selected skills
- Each check script also runs on its own from the command line
- Automated tests for the scripts
